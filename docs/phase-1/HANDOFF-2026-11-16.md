### Randy texting — how it works (verified in code, Nov 16)
- Texting is already built in the booking app (`api/randy-chat.js` → `sendBookingLinkByText` in `lib/randy/businessTools.js`). The website needs no Twilio keys; it only relays chats.
- Flow: customer asks for a booking link → Randy asks for first name and mobile number and shows the consent line ("By providing your mobile number, you agree to receive this booking link and rental-related texts from Little Junkers. Reply STOP to unsubscribe.") → Randy saves a quote in `randy_sessions` with consent text and timestamp → texts the link. If texting fails, Randy shows the link in chat instead.
